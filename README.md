# DimasyyyaOfficeVR

## Описание проекта

**DimasyyyaOfficeVr** — учебное VR-приложение, разработанное в рамках лабораторных работ по дисциплине «Разработка VR-сред».

Проект представляет собой интерактивный симулятор рабочего дня сотрудника футуристического офиса. Пользователь взаимодействует с офисной мебелью, канцелярскими принадлежностями и оргтехникой, выполняет последовательные задачи и управляет виртуальным компьютером с помощью контроллеров VR-гарнитуры.

Проект вдохновлён игровой механикой *Job Simulator* и сочетает моделирование офисного пространства, физическое взаимодействие с предметами и выполнение повседневных рабочих задач в комическом стиле.

## Цель проекта

Разработка интерактивной виртуальной среды, моделирующей рабочий день офисного сотрудника с использованием технологий виртуальной реальности.

Основные задачи:
- Создание трёхмерного офисного пространства с рабочими кабинками и общей инфраструктурой.
- Реализация захвата, перемещения и использования интерактивных предметов.
- Разработка компьютерного интерфейса, встроенного в виртуальную среду.
- Реализация последовательной системы рабочих задач.
- Создание интерактивных принтера, кулера и доски объявлений.
- Организация завершения рабочего дня и перехода в режим свободного взаимодействия(Песочница).

## Функциональные возможности

### Офисное пространство

- Офис открытого типа с рабочими местами.
- Рабочая кабинка с компьютером, монитором, клавиатурой и мышью.
- Офисное кресло, настольная лампа и канцелярские принадлежности.
- Общие зоны с принтером, кулером и доской объявлений.

### Взаимодействие с предметами

- Захват и перемещение объектов с помощью VR-контроллеров.
- Взаимодействие с чашкой, бумагами, папками, степлером и стаканчиками.
- Использование физических свойств объектов для реализации игровых механик.
- Обработка столкновений и взаимодействий между предметами.

### Компьютерный интерфейс

- Виртуальный рабочий стол на мониторе.
- Разделы «Почта» и «Задания».
- Управление интерфейсом с помощью виртуальной мыши, луча контроллера и триггера.
- Отображение сообщений, инструкций и шуточных электронных писем.

### Интерактивная оргтехника

- **Принтер:** приём бумаги, запуск печати и выдача готовых листов.
- **Кулер:** взаимодействие с кнопкой подачи воды и наполнение стаканчика.
- **Доска объявлений:** размещение и удаление стикеров.

### Система рабочих задач

Игровой сценарий состоит из четырёх основных этапов:

1. **Кофе и почта.** Пользователь берёт чашку, выполняет действие употребления напитка и просматривает электронные письма.
2. **Печать отчёта.** Пользователь помещает бумагу в принтер и запускает процесс печати.
3. **Организация документов.** Пользователь собирает листы, скрепляет их степлером и помещает готовые документы в ящик стола.
4. **Перерыв.** Пользователь набирает воду из кулера и выполняет действие употребления напитка.

После выполнения всех задач на мониторе отображается сообщение об окончании рабочего дня. Далее становится доступен режим свободного взаимодействия с виртуальным окружением.

## Установка и запуск

### Необходимые инструменты

- [Godot Engine 4.x](https://godotengine.org/download/).
- Настроенное окружение OpenXR.
- Совместимая VR-гарнитура и контроллеры.
- Дополнительные плагины и ресурсы, необходимые проекту.

### Запуск из исходного кода

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Dimasyaaa/DimasyyyaOfficeVR.git
   ```

2. Перейдите в каталог проекта:

   ```bash
   cd DimasyyyaOfficeVR
   ```

3. Откройте файл `project.godot` в Godot Engine 4.x.
4. Дождитесь импорта ресурсов и проверьте наличие необходимых плагинов.
5. Настройте OpenXR и подключите совместимую VR-гарнитуру.
6. Запустите проект из редактора и проверьте работу интерактивных объектов и системы задач.
